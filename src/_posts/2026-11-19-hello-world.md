Every engineer eventually rebuilds their personal site. This is mine.

I'm going to use this space to write about the things I'm building, the
problems I run into, and the occasional opinion I can't keep to myself.

> Write it down. Future you will be grateful.

## How this site works

It's a static site built with [Bridgetown](https://www.bridgetownrb.com/).
New posts are just Markdown files dropped into `src/_posts`:

```ruby
# src/_posts/2026-11-19-hello-world.md
puts "Hello, world!"
```

That's it. More soon.
