Every software developer eventually rebuilds their personal site. This is my next attempt.

I'm going to use this space to write about the things I'm doing, the
problems I run into, and the occasional unrelated post about whatever I please.

## How this site works

It's a static site built with [Bridgetown](https://www.bridgetownrb.com/).
New posts are just Markdown files dropped into `src/_posts`:

```ruby
# src/_posts/2026-11-19-hello-world.md
puts "Hello, world!"
```

Push it to Github and wire it up to deploy to Netlify.

I chose Bridgetown because it's Ruby and very easy to build with. I work with Ruby every day (Rails to be more precise) and I've really come to
love the language over the years. Bridgetown had a quick onboarding, and that made me happy.

As for styling and my personal taste, I've liked sites that have a [Neobrutalism](https://neubrutalism.com/) feel, so I took a chance on it. 

Did AI help create this? Yes, of course! Am I conflicted about it? Yes, of course! But that's the reality of software and web development these days.
